# Changelog

## v1.0

- Added one shared text input for complete Bet365 multi-meeting exports.
- Added automatic detection of five bundled meetings and 39 races.
- Added dynamic meeting tabs, race tabs and parsed-data subtabs.
- Added scratchings and active-field handling.
- Added Bet365 Analyst, Independent Form, Suitability/Fitness and Pace/Draw specialist models.
- Added full finishing order, win probability, top-three probability, expected rank, fair odds and 0-9 confidence.
- Added horse-specific explanations.
- Added raw TAB-style result parsing, partial results and dead heats.
- Added continuous pairwise retraining.
- Added automatic `model_state.json`, training-store, history, snapshots and backups.
- Seeded the initial state with 35 completed races; Port Hedland R4-R7 remain pending.
- Added odds-mutation invariance tests confirming 0% direct price influence.
